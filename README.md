# Supermarket Sales Analysis — PostgreSQL

A small SQL project where I explored a supermarket sales dataset using PostgreSQL.

The goal was to practice SQL in a more practical, business-focused way rather than just solving isolated exercises.

What I worked on

- Explored 9,800+ sales records
- Analyzed sales by category, sub-category, region, customer and time
- Built 20 SQL queries from basic to advanced
- Used `GROUP BY`, `HAVING`, `CASE`, subqueries and CTEs
- Practiced window functions with `RANK()` and `PARTITION BY`
- Extracted business insights from the analysis

Tools

- PostgreSQL
- pgAdmin
- SQL
